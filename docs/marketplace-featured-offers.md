# مصدر العروض الذكية

تستخدم واجهة Marketplace وحدة **Advertising** كمصدر أول للعروض المميزة. يضع endpoint الدليل المنشآت التي لديها إعلان `ACTIVE` غير منتهٍ في المقدمة، سواء كان الإعلان مرتبطًا بالمنشأة مباشرة أو بمنتج/خدمة تابعة لها. كما يدعم المصدر حملات `ACTIVE` المرتبطة بالمنشأة عبر `advertisers.business_id` مع احترام نافذتي `starts_at` و`ends_at`.

اختير هذا المصدر لأنه يمثل حالة التمييز التجارية الفعلية المعتمدة في النظام، بدل اعتبار ترتيب نتائج قاعدة البيانات تمييزًا إعلانيًا. إذا لم توجد منشآت لها إعلان أو حملة نشطة حاليًا، يعيد endpoint القائمة بترتيب صريح `businesses.created_at DESC`، وتستخدم الواجهة هذا الترتيب كـfallback بدل `slice` غير المفسر.

ويظل العرض المميز عرضًا للمستخدم العادي فقط؛ لا يضيف هذا المسار أي صلاحيات أو روابط إدارية.
